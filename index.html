    Sources & methods

    Download snapshot ↓

    Public data from api.taskmarket.dev. A server-side collector runs twice an hour. The page checks the cached snapshot every five minutes while visible. Upstream delays leave the last successful snapshot in place. Times and buckets use UTC. The API returns matching platform series for both network queries. We show those amounts in reported units. Network rewards come from the task list and use OUSD on Tempo or USDC on Base.
